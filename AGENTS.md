# Project Development Mode

This project follows:

Research Prototype / Engineering Validation Mode.

The primary goal is rapid iteration, hardware validation, and algorithm verification.

Priorities:
1. Functional correctness
2. Debuggability
3. Development speed
4. Maintainability

Avoid unnecessary production-level complexity.

Do not introduce:
- excessive abstraction
- unnecessary design patterns
- enterprise architecture
- extensive defensive programming
- complex error recovery systems
- security mechanisms unrelated to the project goal

Assume controlled development environment unless explicitly stated otherwise.

When identifying potential risks:
- explain the risk
- propose possible solutions
- do not implement large-scale solutions without approval.

Prefer simple, readable implementations.
