## 3. 使用约束

- 使用前核实所选分支、依赖和 ROS 版本，不把这些仓库全部直接塞进工作空间编译。
- 涉及飞控通信时，同时核实 PX4 固件版本及接口兼容性。
- `px4-ros2-interface-lib` 的外部模式机制不等同于 MAVROS Offboard 封装；使用前匹配 PX4、`px4_msgs` 和库的分支版本。加入参考清单不代表当前切换通信路线或安装该库。
- 按实际需求借鉴对应模块，不因参考仓库包含某个框架或控制器就直接引入。
- 自写功能包使用 C++；YOPO 等训练流程可以保留 Python。现有 ROS 2 Python launch 属于启动编排。
- 文档中的借鉴方向是项目意图，不能作为本地实现、SITL 或实机验证证据。

当前自写包的实现状态与待讨论事项见 [任务与控制架构现状及讨论记录](任务与控制架构现状及讨论记录.md)。
