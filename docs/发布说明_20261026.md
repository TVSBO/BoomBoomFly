## 分类原则

保留原项目主工程/工作区/功能包边界，形成 BoomBoomFly、uav_ws、uav_control、uav_vio_bridge、
uav_bringup、uav_mission、open_vins 七个独立仓库。uav_interfaces 嵌套于 uav_control。
原有未提交源码修改随所属功能仓库发布；新增 SOURCE.md 保留原仓库、基线和历史边界。
没有旧 .git，故建立新提交历史；不声称保留原 fork 历史。保留许可证、作者与版权头。

## 相对原主仓库说明的变化

- MAVROS 单后端扩展为 DDS/MAVROS，当前采用 DDS。
- 简单位姿转发扩展为 IMU/Odometry 适配、视觉健康、协方差及连续性检查。
- launch 统一编排控制、任务、Agent、相机、OpenVINS 与桥接。
- 增加等待遥控器解锁、方形和九宫格 S 形往返任务。
- 加入 Orange Pi 配置、相机—飞控 IMU 标定、DDS 本地视觉航向就绪处理。
- 保留 PX4 V3 时间同步补丁与历史同步/融合记录。
- README 更新为当前实际配置，原包说明归档，不改变飞行源码及部署参数。
